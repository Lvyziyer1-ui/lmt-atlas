Glossary

Plain-language definitions for the public v3.0 static release. CSV and SQLite downloads retain internal schema fields for ML and reproducibility.

Terms

Item ⓘDetails ⓘ
Methanol Tolerance Score (MTS)The frozen continuous construct-level score shown on public pages. Lower number = more methanol tolerant, and the uncertainty range plus confidence should be read with the point estimate.
MTS download mappingPublic MTS = download column LTS_ref, together with the LTS_ref_ci_low and LTS_ref_ci_high uncertainty columns.
Display tierReader-facing evidence-support bucket. Evidence-rich, moderate, sparse, and absent support summarize how many reliable observations support the public row.
Reference conditionsThe current unified reference challenge used to compare score values across rows: 50% methanol, about 2 h, and 25 °C.
Evidence-rich supportThe strongest public display bucket; relatively many reliable observations support the row.
Moderate evidence supportA middle public display bucket; several reliable observations support the row.
Sparse evidence supportA weaker public display bucket; only a few reliable observations support the row.
Evidence absentThe row remains visible but lacks reliable methanol observations for the public display tier.
Uncertainty rangeThe range around a score that shows how certain we are about the estimate. Wide ranges mean the comparison should be treated cautiously.
ConfidenceHow much support the score has after checking baseline activity, missing assay context, source traceability, and sensitivity to evidence choices.
Display-tier badgePublic badge shown as Evidence-rich, Moderate evidence, Sparse evidence, or Evidence absent. It summarizes evidence support and does not replace the numeric score.
Fit statusWhether the score is directly supported, supported by limited evidence, insufficiently supported, or not applicable.
Enzyme groupReader-facing family band. WT and engineered constructs are shown together when they belong to the same family.
Enzyme family bandReader-facing group used for Search filters and organism browsing. Download tables keep the original grouping fields for reproducibility.
evidence tierEvidence strength tier: strong, moderate, or limited support after assay and provenance checks.
source typeWhether support comes from literature, patent evidence, both, or no linked methanol-tolerance evidence.
assay method classBroad measurement-readout group, such as spectrophotometric/colorimetric, fluorometric, titrimetric/pH-stat, or biodiesel-conversion assays.
substrate classBroad substrate group used to make condition filters easier to scan before choosing exact substrates.
SEQ ID NOSequence Listing ID in a patent sequence listing.
family tolerance summaryA group-level overview that helps users inspect trends; it is not a substitute for construct-level evidence.

Lower number = more methanol tolerant (lower = more tolerant). A lower MTS means the enzyme or construct is estimated to carry less methanol-induced inactive burden under the reference challenge.

Reference conditions: Reference conditions: 50% methanol / about 2 h / 25 °C.

Public pages intentionally avoid internal primary keys and workflow fields in table headers. Use the downloadable CSV/SQLite bundle when exact IDs, protocol keys, or provenance fields are required for computation.
