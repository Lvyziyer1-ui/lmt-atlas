Related databases

Use exact UniProt, PDB, NCBI protein, and EC identifiers to move between LMT-Atlas and sister protein resources.

Reverse mapping into LMT-Atlas

Paste a UniProt accession, PDB ID, NCBI protein accession, EC number, DOI, patent number, enzyme name, species, strain, or LMT ID into Search. The static Search index is generated from the current canonical identity and display layers.

Entry pages expose Related resources only when an exact, non-sentinel identifier exists for that entry.
