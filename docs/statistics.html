Strict-response protocol routing

The current routing separates 582 coarse condition units from 1037 exact protocol units. Of the exact units, 320 support strict response analysis and 717 do not. At coarse-condition level, 220 units include at least one usable exact protocol and 362 include only unavailable exact protocols.
