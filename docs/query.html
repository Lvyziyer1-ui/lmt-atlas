LMT-Atlas

Query the v3.0 data

Use Datasette Lite in the browser, download SQLite and CSV files directly, or run Datasette locally. The static site does not provide online JSON endpoints or a persistent database server.

Three executable paths

  1. Datasette Lite: open Datasette Lite and load the downloaded v3.0 SQLite file in the browser. This route may depend on an external CDN.
  2. SQLite and CSV downloads: download SQLite or download the CSV bundle; these remain available if the CDN is unavailable.
  3. Local Datasette: install Datasette and run python -m datasette lmt_atlas_v3_0.sqlite -m metadata.json. JSON output is available only from that locally operated Datasette process.

Copyable exact queries

Exact UniProt Q6WER3

select canonical_enzyme_id, display_name from all_enzyme_index
where uniprot_link_relation = 'exact'
and instr(';' || upper(replace(coalesce(exact_uniprot_ids, ''), ',', ';')) || ';', ';Q6WER3;') > 0;

Exact PDB 3NGM

select canonical_enzyme_id, display_name from all_enzyme_index
where pdb_link_relation = 'exact'
and instr(';' || upper(replace(coalesce(pdb_ids, ''), ',', ';')) || ';', ';3NGM;') > 0;

DOI 10.1371/journal.pone.0286091

select canonical_enzyme_id, display_name from all_enzyme_index
where lower(doi_or_patent_number) = lower('10.1371/journal.pone.0286091')
order by canonical_enzyme_id;

Identifier boundary

Exact examples include only identifiers whose relation is recorded as exact for that construct. Parent, historical, and unverified identifiers remain archival provenance and must not be interpreted as exact construct matches.

Offline query boundary

The release supports offline SQLite and CSV analysis. No hosted REST API is provided.

Strict comparison boundary

Strict comparability is limited to released measurements that satisfy the strict condition contract and exact measurement context. Heterogeneous observations remain available with explicit warning and manual_review states.
