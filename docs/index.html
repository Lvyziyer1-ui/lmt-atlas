Lipase Methanol Tolerance Atlas

A curated evidence database for enzyme-intrinsic methanol tolerance in TAG lipases, linking canonical enzyme identities, constructs, assay protocols, quantitative measurements, and literature/patent provenance.

Release note: Web v2.1 — structure viewer added (Mol*/NGL 3D + mutation highlight); data unchanged at v2.0 (Zenodo DOI 10.5281/zenodo.21124634).

Search entries Browse by Organism Download tables

Because assay conditions are heterogeneous, filter by temperature, assay method/substrate, methanol concentration, and exposure time before comparing entries.

Search exports are condition-filtered comparable subsets; exported tiered labels are temporary analysis views derived from frozen scores.

The public badge is a coarse confidence tier with 37 More tolerant, 38 Less tolerant, and 365 Uncertain constructs; it complements continuous scores rather than replacing them.

Continuous methanol tolerance score primary. Public pages use the frozen methanol-tolerance score (internal field LTS_ref) with an uncertainty range and a confidence badge as the main tolerance summary. Lower number = more methanol tolerant. Internal archive fields remain available in CSV and SQLite downloads for reproducibility.

How To Use This Database

Find whether an enzyme has methanol data

Search names, species, canonical IDs, UniProt, PDB, EC, DOI, and patent numbers, then open the matching entry.

Compare variants of one enzyme

Open a source organism, then a strain, then inspect WT and mutant constructs in the same series.

Download data for modelling

Use CSV/SQLite tables generated from the same frozen v2.0 release snapshot, including measurement and protocol layers.

Data Model

1. Enzyme SpeciesCanonical ID, species, EC, identifier status, structure readiness.
2. Variant / ConstructWT, mutant, engineered construct, parent-child boundary.
3. Assay ProtocolChallenge context, A0 quality, buffer, temperature, enzyme concentration.
4. MeasurementMethanol concentration, time, residual activity, extraction method.
5. SourceLiterature DOI, patent publication, figure/table anchor, caveat.

Scope And Citation

This Web v2.1 static site supports browsing, search, provenance inspection, table download, 3D structure viewing, and mutation-site highlighting for the locked source-scope publication bundle.

Data layer and public download scope remain v2.0; no new Zenodo version was issued for this display-layer update.

Structural module rule claims and family taxonomy conclusions remain outside this display release. Official tolerance fields are active for the v2.0 web publication scope.
