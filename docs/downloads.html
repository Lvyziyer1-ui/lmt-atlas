Programmatic Use

CSV and SQLite downloads retain internal fields needed for reproducibility. Public HTML pages hide internal workflow tokens and expose reader-facing labels.

Open SQL query guide · Open documentation

Strict comparison boundary

Strict comparability is limited to released measurements that satisfy the strict condition contract and exact measurement context. Heterogeneous observations remain available with explicit warning and manual_review states.
