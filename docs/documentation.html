Documentation

Methods, definitions, and practical guidance for using the LMT-Atlas v3.0 static release without rewriting source evidence tables.

How To Use This Database

  • Use Search for enzyme names, species, UniProt, PDB, NCBI protein, GenBank, RefSeq, DOI, patent numbers, and exact provenance IDs.
  • Use Search to filter the full canonical enzyme/construct identity index.
  • Use Statistics for current display-layer distributions and Related databases for cross-resource identifier mapping.
  • Read the methanol-tolerance score, 95% interval, confidence, and fit status as the primary tolerance summary.
  • Read the public display tier as a coarse reader summary: Evidence-rich support 126, Moderate evidence support 104, Sparse evidence support 201, Evidence absent 180.
  • Additional archive labels remain available only in downloads; they are not used for headlines or Search filtering.
  • Use the Assay Evidence Matrix on linked entries to inspect methanol concentration, incubation time, residual activity, and protocol grouping.
  • Because assay conditions are heterogeneous, filter by temperature, method, concentration, and time before comparing entries. Raw residual activity across conditions is not directly comparable.
  • Separate literature evidence, patent evidence, and process-confounded evidence when interpreting the source mix.
  • Download full tables or use the Export Wizard on Search to export the current filtered subset as continuous-score rows or conservative tiered labels.

All public records now resolve to canonical construct entry pages.

Intrinsic Methanol Tolerance

Intrinsic methanol tolerance refers to free-enzyme methanol challenge evidence with explicit methanol concentration, exposure time or feeding mode, and a clearly defined activity or residual activity readout. Reactor-scale biodiesel outcomes are kept separate as process-confounded evidence.

Evidence Tiers

  • Strong direct evidence: free-enzyme methanol challenge data with usable assay context and provenance.
  • Process-confounded evidence: retained for context, not used as the main tolerance signal.
  • Mechanism or background evidence: useful for interpretation, not for tolerance scoring.

Official Score Display

MTS is the public tolerance metric. Public pages use the frozen Methanol Tolerance Score (MTS) with an uncertainty range and a confidence badge as the main tolerance summary. Lower number = more methanol tolerant. Internal archive fields remain available in CSV and SQLite downloads for reproducibility.

This score is a calculated value, not a single experimental readout.

Measurements collected at different methanol concentrations, exposure times, and temperatures are normalized to the fixed reference conditions before scores are compared.

Reference conditions: 50% methanol / about 2 h / 25 °C

Lower number = more methanol tolerant.

Every score is shown with an uncertainty range and an observation-support tier; a lower support tier means less evidence, not lower methanol tolerance.

The public display tier is a reader summary with Evidence-rich support 126, Moderate evidence support 104, Sparse evidence support 201, Evidence absent 180.

Evidence-rich support means relatively many reliable observations.

Moderate evidence support means several reliable observations.

Sparse evidence support means only a few reliable observations.

Evidence absent means the row is visible but lacks reliable methanol observations.

  • Display tier: reader-facing support tier used for headline counts, Search filters, and table scanning.
  • Archive labels: retained in downloads/SQLite for audit; many rows have wide intervals or low support because the measurement set is sparse, heterogeneous, or sensitivity-dependent.

Score Inference

The official values come from a preregistered score workflow with an independent cross-check. The cross-check supports the frozen values for converged constructs.

The score is derived from residual-activity evidence only when baseline activity interpretation is reliable. Confidence is reduced when baseline quality, extraction method, evidence strength, missing context, or sensitivity checks are weak.

Rows marked enzyme_form=crude_preparation are retained at construct level, but their public score display carries a crude preparation — downweighted caveat. Rows confirmed as free purified, including san-ai lipase, do not carry the crude-preparation caveat. The frozen score point estimate is not changed; only the adjusted display confidence is capped and the penalty is recorded in downloadable provenance fields.

Assay Comparability

Because assay conditions are heterogeneous, users should filter by incubation temperature, assay method/substrate, methanol concentration, and exposure time before comparing entries. Cross-condition raw residual activity values are not directly comparable; the database exposes all measurement rows and conditions so users can construct comparable subsets.

The Export Wizard supports condition-filtered comparable subsets, optional tiered labels with conservative gating, and optional reverse-mutation augmentation for WT-variant data-analysis views. These exported labels are derived from frozen score values and are not new official labels.

Source Count Metrics

literature_source_count counts valid DOI entries in source_reference.csv with source_type=literature; this is the source-layer headline metric and current direct evidence source count. registry_literature_breadth counts distinct DOI-bearing Phase 1A registry sources across direct_intrinsic, process_confounded, mechanism_only, and background_only evidence; it is reported as registry breadth only and does not satisfy the 180 source-layer target. direct_intrinsic_source_count is the subset of distinct DOI-bearing publications that contribute direct_intrinsic literature rows to the main methanol-challenge evidence layer.

Curation SOP

The document-layer curation policy for this release is defined in the current SOP and applies the same inclusion, provenance, assay-context, and quality-control rules used for the downloadable bundle.

PDB anti-inheritance

Mutant and engineered construct rows do not inherit parent experimental PDB IDs by default. If no mutant-specific structure is confirmed, the page reports that no exact construct-specific PDB is available and records any parent-scaffold caveat separately.

Reviewer checklist

Release review checks cover canonical entry closure, public-governance consistency, protocol-level disposition completeness, and integrity validation of the atlas source tables after each rebuild.

Release Boundaries

This release uses one canonical construct-entry route for the full object set. Historical benchmark pages remain archival inputs and are not published.

Evidence strength is expressed uniformly through confidence, uncertainty ranges, and fit status instead of entry-specific warning text.

Strict comparison boundary

Strict comparability is limited to released measurements that satisfy the strict condition contract and exact measurement context. Heterogeneous observations remain available with explicit warning and manual_review states.
