# MeTLA — an atlas of lipase methanol tolerance (v3.0)

**Live site:** https://lvyziyer1-ui.github.io/lmt-atlas/

**Version DOI:** https://doi.org/10.5281/zenodo.23353309

**Zenodo record:** https://zenodo.org/records/23353309

**Concept DOI (always points at the latest release):** https://doi.org/10.5281/zenodo.20908851

MeTLA (an atlas of lipase methanol tolerance) is a curated evidence database of
methanol-tolerance data for triacylglycerol lipases (EC 3.1.1.3). Version 3.0 contains
671 canonical enzyme entries, 611 construct-level records — 431 of them carrying a
reliable public Methanol Tolerance Score — and 2,857 measurement rows drawn from 849
assay protocols and 215 traceable literature and patent sources.

The repository name and Pages path stay `lmt-atlas`; MeTLA is the platform name.

This repository hosts the static website served by GitHub Pages from `/docs`. The v3.0
download bundle, SQLite database, data dictionary, model card, and integrity manifests
are available through the live site; the final archival ZIP is preserved at the version
DOI above.
